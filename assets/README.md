# Assets Directory

This directory contains project assets (logos, icons, images).

## Recommended Files

| File | Description |
|------|-------------|
| `logo.svg` | Vector logo (preferred for web) |
| `logo.png` | Raster logo (512x512px recommended) |
| `icon.png` | Application icon (square, 256x256px+) |
| `favicon.ico` | Browser favicon (16x16, 32x32) |

## Usage

- **README.md**: Reference logo with `![MeSame](assets/logo.png)`
- **Frontend**: Import from `../assets/` when dashboard is implemented
